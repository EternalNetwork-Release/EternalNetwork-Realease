## 中文

Eternal Network 是一个面向日常访问、流媒体和开发工作的精品网络服务介绍页，主打低延迟、稳定连接和多平台支持。页面中的服务信息、套餐说明、客户端指引和支持渠道均可切换为中文、English、Русский、فارسی或 العربية。

### 服务特点

- IEPL 专线：16 元起的套餐提供 IEPL 专线，部分高阶套餐提供 IPLC；线路负载较低，适合重视延迟和稳定性的用户。
- AnyTLS 协议：支持 TUN、全局、规则以及校园网/内网模式，并支持订阅一键导入和更新。
- 流媒体访问：支持 YouTube、Netflix、Disney+、Spotify 等服务的注册与访问，并可使用 [RegionRestrictionCheck](https://github.com/lmc999/RegionRestrictionCheck) 检测区域解锁情况。
- 多平台客户端：覆盖 Windows、macOS、Android、Linux 和 OpenWrt；iOS 按文档使用 Shadowrocket，订阅用户可获得共享美区 Apple ID 下载应用。
- 社区支持：官网文档适合查步骤，工单适合跟进具体问题，Telegram 群组可联系群主、管理员和其他用户。

## English

Eternal Network is a multilingual service brief for a low-latency, stable network service aimed at everyday browsing, streaming, and development workflows. The page documents IEPL/IPLC routes, AnyTLS connections, supported clients, monthly plans, and community support.

### Highlights

- IEPL routes are included from the CNY 16 plan; the highest plan uses IPLC.
- AnyTLS supports TUN, global, rule-based, campus, and intranet modes, with one-click subscription import and updates.
- YouTube, Netflix, Disney+, Spotify, and other services can be checked with [RegionRestrictionCheck](https://github.com/lmc999/RegionRestrictionCheck).
- Clients are available for Windows, macOS, Android, Linux, and OpenWrt. iOS users can follow the Shadowrocket guide and use the shared Apple ID provided to subscribers.
- Documentation, tickets, and the [Telegram community](https://t.me/Etcloud) are available for support.

See the [official website](https://etcloud.top/#/register?code=QkfuWy3i) for current pricing and route availability.

## 本地预览与部署

项目是无需构建工具的纯静态 HTML 页面。直接打开 `index.html` 即可预览，也可以运行：

```bash
python -m http.server 8000
```
