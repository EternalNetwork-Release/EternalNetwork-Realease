01 / SERVICE BENEFITS

Eternal Network的服务

IEPL线路、AnyTLS协议、抗封锁能力强、所有设备可用。

线路体验小众精品专线机场。每 GB 价格较高，低价套餐流量较少，但线路负载低。16 元以上套餐提供 IEPL 专线，群友会监督并反馈不可用线路，鞭策后的服务就是好用👌。
流媒体解锁YouTube、Netflix、Disney+、Spotify 等服务可注册并访问。购买套餐后导入代理软件，开启 TUN 模式，可在 macOS 终端或 Windows Git Bash 运行 bash <(curl -L -s check.unlock.media) 做解锁检测，方法见 RegionRestrictionCheck。
连接模式支持 TUN、全局和规则模式，也有校园网 / 内网模式。订阅可一键导入和更新，网络波动时客户端会自动重试。
路由器覆盖OpenWrt 支持路由级代理，家里的多台设备可以一起使用，不必逐台安装客户端。
iOS 使用iOS 按文档使用 Shadowrocket，订阅用户可获得共享的付费美区 Apple ID 供下载应用。
抗封锁协议AnyTLS 将订阅内容与连接流量分开保护，减少节点信息被直接获取。它的抗封锁能力与 VLESS + Reality 同属第一梯队，保障特殊时期的流畅使用。
支持渠道官网文档适合查步骤，工单适合跟进个体问题，Telegram 群聊可以直接联系群主和管理员，也有群友帮忙排查。
