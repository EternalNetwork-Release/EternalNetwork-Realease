01 / Getting started

开始使用

在面板查看最新套餐，按照使用文档安装并配置客户端。

  1. 01注册与登录

    使用有效邀请链接注册，然后登录用户面板。

  2. 02查看当前套餐

    进入「购买订阅」，查看最新价格、流量、线路和适用条件后再选择。本页不展示未经核实的套餐价格。

  3. 03安装专用客户端

    打开面板「使用文档」，按首篇教程下载安装。面板公告说明专用客户端与其他客户端使用的线路不同，建议使用专用客户端。

  4. 04登录或导入订阅

    按教程完成配置，并及时更新订阅。已有用户可重新导入订阅，App 用户可重新登录。

02 / Support

需要帮助？

先查看面板文档；涉及账户或付款的问题可提交工单。

客户端连接

Windows 客户端提示无法连接网站时，面板建议退出登录后重新登录，或重新安装客户端。

节点与订阅

请及时更新订阅。Shadowrocket 没有节点或只显示两个节点时，面板建议更新软件。

付款与支持

付款未到账可在面板「我的工单」提交问题。也可前往 Telegram 群组或查看 Telegram 频道。
